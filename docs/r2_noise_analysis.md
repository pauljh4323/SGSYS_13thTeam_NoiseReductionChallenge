# Round-2 noise analysis: where gru_v5b loses PESQ (branch exp/r2-noise-analysis)

Analysis only (2026-11-19). No training, no change to `main.py`, `configs/submission.yaml` or any weights. The method is
gru_v5b exactly as submitted (`configs/dl/gru_v5b_off.yaml`, r2-prep). Script: `scripts/r2_noise_analysis.py`
(code at clean hash 16b41ba; stage `compute` runs `--jobs 4` for ~10 min, stage `report` writes the tables, CSVs and figures).
Full tables: `logs/r2_noise_analysis_tables.md` (git-ignored, regenerated by `--stage report`). Per-file CSV:
`results/r2_noise_analysis_files.csv` (492 rows). Per-type CSV: `results/r2_noise_analysis_types.csv`. These are analysis
outputs, not candidates, so nothing was appended to `results/experiments.csv`.

**Pool.** validation (164) + val_remix (328) = 492 files, with a `source` column. Caveat: val_remix reuses validation's noise
recordings (docs: exp/r2-diag), so the 492 files are not independent per noise recording. Per-type confidence intervals are
therefore optimistic, and types with n ≤ 6 (8 Nonspeech transient types, 27 files, 7.3 % of headroom) are indicative only.

## Method

| quantity | definition |
|---|---|
| v5b PESQ / SNR | registered method output, quantised to 16-bit PCM as main.py writes it; pesq 0.0.4 `wb`, course SNR |
| shadow filtering (Loizou & Kim 2011) | v5b's own real mask M (torch STFT 512/128 periodic Hann, centre/reflect) applied separately: s_hat = iSTFT(M·S), n_hat = iSTFT(M·N), with N = STFT(noisy − clean) |
| distortion-only PESQ | PESQ(clean, s_hat) (no noise at all, only the mask's effect on speech) |
| residual-only PESQ | PESQ(clean, clean + n_hat) (undistorted speech plus the noise v5b lets through) |
| resid dB / speech dB | 10·log10(Σn_hat² / Σn²) / 10·log10(Σs_hat² / Σs²) (negative = attenuated) |
| oracle IRM (headroom reference) | sqrt(\|S\|²/(\|S\|²+\|N\|²)) on the noisy STFT, noisy phase, same setup as the O-oracles in docs/exp_oracle.md (scipy Hann 1024 / hop 256, 100 Hz zero-phase high-pass, 16-bit). O4 (Wiener, no sqrt) also reported |
| headroom | PESQ(IRM) − PESQ(v5b), per file; "share" = Σ headroom over the group / Σ over all 492 |
| deficit contribution | Σ(4.64 − PESQ) over the group / 492 (sums to the pool's mean deficit 2.063) |
| dominant error | the larger of the mean distortion-only drop (4.64 − PESQ(s_hat)) and the mean residual-only drop (4.64 − PESQ(clean + n_hat)) |
| noise descriptors (from n = noisy − clean, STFT 512/128) | stationarity = std over frames of the log band power (16 log-spaced bands, 100 Hz–8 kHz), averaged over bands (dB); spectral centroid of the mean PSD; low/high = 10·log10(E < 1 kHz / E ≥ 1 kHz); flatness = geometric/arithmetic mean of the mean PSD (≥ 50 Hz), and the per-frame flatness averaged over frames (`flatness_frames`) |

**Checks.** The 16-bit v5b scores reproduce the recorded eval.py per-file rows exactly (validation 2.6962, val_remix 2.5170;
max |ΔPESQ| = max |ΔSNR| = 0). The explicit mask path equals the registered method bit-exactly (max |diff| 0). **Shadow
consistency: max |s_hat + n_hat − v5b output| = 2.6e-7 over all 492 files (float32 round-off); after 16-bit quantisation ≤ 1 LSB
(3.05e-5).** No PESQ failures. A second full run gave bit-identical numbers.

- Pool mean deficit 4.64 − 2.577 = 2.063, of which the magnitude-only oracle recovers 0.739 (36 %). The rest needs phase or is
  out of reach for a noisy-phase mask. (O4 Wiener: +0.805. The IRM is below v5b on 35 files: alarm_siren 19, phone_dialing 9.)
- **Distortion and residual noise cost about the same overall** (drops 1.355 vs 1.337; distortion dominates in 50.4 % of
  files, which hold 56 % of the headroom). v5b removes 11 dB of noise on average and attenuates speech by only 0.6 dB, but
  the speech it keeps is spectrally damaged enough that distortion-only PESQ is just 3.29.
- The split flips with SNR: **distortion dominates at 0 and 5 dB, residual noise at 10 and 15 dB**.
- Headroom per file correlates with the distortion-only drop (Spearman +0.71) more than with the residual-only drop (+0.64),
  and with speech attenuation (−0.48), but not with the residual level in dB (−0.05). So files with large headroom are
  those where the mask cuts speech, not those where more noise is left.

## Noise descriptors vs headroom

Spearman ρ over the 23 types (type means), and per file (n = 492):

| descriptor | ρ vs type mean headroom (p) | ρ vs type headroom share (p) | ρ per file (p) | per file within SNR 0 / 5 / 10 / 15 dB |
|---|---|---|---|---|
| stationarity (dB) | +0.14 (0.53) | −0.47 (0.02) | −0.00 (0.93) | +0.03 / −0.04 / −0.01 / −0.01 |
| spectral centroid | +0.29 (0.18) | +0.10 (0.65) | +0.22 (6e-7) | +0.39 / +0.21 / +0.25 / +0.12 |
| low/high energy ratio | −0.30 (0.17) | −0.04 (0.85) | −0.22 (2e-6) | −0.39 / −0.18 / −0.22 / −0.15 |
| flatness (mean PSD) | +0.53 (0.009) | +0.17 (0.45) | +0.46 (1e-27) | +0.52 / +0.62 / +0.51 / +0.43 |
| **flatness (per frame, mean)** | **+0.80 (< 0.001)** | +0.01 (0.97) | **+0.48 (5e-30)** | +0.59 / +0.66 / +0.52 / +0.42 |

- **Spectral flatness is the strongest predictor of per-file headroom.** Noise that looks noise-like (flat, broadband:
  broadband_noise 0.43, aircraft_cockpit 0.22, water, shower, tooth_brushing) leaves the most headroom. Tonal or peaky noise
  (phone_dialing 0.000, vehicle_interior 0.001, alarm_siren 0.02, wind 0.006) leaves the least, because v5b already removes
  it. The effect holds within every SNR (ρ +0.42 to +0.66), so SNR mix does not explain it.
- Stationarity does not predict headroom per file (ρ ≈ 0). Its negative correlation with the type *share* only reflects that
  the frequent types (machine, wind, aircraft) are fairly stationary. Low-frequency noise (high low/high ratio) leaves
  slightly less headroom.
- Share is mostly frequency (n) times mean headroom, so no descriptor predicts the share (|ρ| ≤ 0.17 except stationarity).

## Conclusions: which error to trade for PESQ

1. **Group A: broadband / low-frequency stationary noise, distortion-dominant** (machine, wind, aircraft_cockpit,
   broadband_noise, traffic_vehicle, destroyer_*, military_vehicle; 73.5 % of headroom). v5b over-suppresses: it cuts speech
   (−0.7 to −0.9 dB, more at 0–5 dB) to buy −9 to −10 dB of noise. **Trade residual noise for less speech distortion**: a
   higher mask floor, less aggressive masks at low local SNR, or a speech-preserving loss term. This matches the exp/r2-diag
   finding that mixing in 25 % of the gentler dsp-v8 output helps exactly these categories, and the flatness result: v5b is
   weakest where speech and noise overlap across the whole band.
2. **Group B: tonal / impulsive / non-stationary noise, residual-dominant** (alarm_siren, bell, water, hf_channel,
   vehicle_interior, transients; 26.5 %). Speech is nearly intact for the tonal ones (dist-only 3.97 alarm_siren, 3.99 bell, 4.23 vehicle_interior); water and hf_channel lose on both errors. **Trade some
   distortion for more suppression**, e.g. a lower floor or a stronger penalty on residual noise when the noise is peaky.
   alarm_siren and phone_dialing are close to or above the IRM already, so little is left there.
3. **SNR.** At 0–5 dB distortion dominates, at 10–15 dB residual noise dominates. A single global floor change would help
   one end and hurt the other. Any trade-off has to be conditional on the input (estimated local SNR or noise flatness),
   not global.
4. **Priorities.** machine (22.7 %) and wind (14.8 %) are the two biggest single targets, and are frequent in train (264 and
   202 files per exp/r2-diag), so data scarcity does not explain them. The rare transient types (n ≤ 6) are only 7.3 % of
   the headroom: low priority despite their large per-file headroom.
5. Remember the ceiling: the magnitude-only oracle recovers 36 % of the pool deficit (O4 39 %). The remaining 1.32 PESQ
   needs phase (docs/exp_oracle.md, docs/round2_plan.md) or is the IRM's own limit.
